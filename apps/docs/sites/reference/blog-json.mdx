`blog.json` sits at the root of your site folder. Every setting is optional except `name`, and the whole file is optional too, so without it the site builds with the defaults below and the site name from the dashboard.

## JSON Schema

Start the file with `$schema` to get autocomplete and inline errors in VS Code, Cursor, Zed and JetBrains editors:

```json blog.json
{
  "$schema": "https://usenotra.com/schemas/blog.json",
  "name": "Acme"
}
```

Notra publishes the schema at [usenotra.com/schemas/blog.json](https://usenotra.com/schemas/blog.json) (JSON Schema draft 2020-12), and you can also use it to validate the file in CI or generate types:

```bash
curl -s https://usenotra.com/schemas/blog.json | npx json-schema-to-typescript > blog-config.d.ts
```

## Validation

Every build checks `blog.json` before it builds anything, and mistakes stop the build, with the deployment log and the GitHub check naming the setting and what to change:

```text
✖ blog.json  blog.layout: Invalid option: expected one of "grid"|"list"|"magazine"|"cards"
```

- Notra ignores an unknown top-level setting with a warning that suggests the closest match, like `Unknown setting "navBar" is ignored. Did you mean "navbar"?`.
- Unknown keys inside `authors`, `integrations` and `security` stop the build, because a typo there would turn something off without any warning.
- Notra ignores other unknown nested keys.

The tables below use these shared formats:

| Format | Rule |
| --- | --- |
| Color | Hex with 3 or 6 digits, like `#0D9373` |
| Path | A file in your site, like `/images/logo.svg`, or a full URL |
| Link | A path starting with `/`, an `http(s)://` URL or a `mailto:` address |
| Icon | A [Lucide](https://lucide.dev/icons) icon name from the [list below](#icons), like `book-open` |

## Icons

Notra bundles a set of Lucide icons, and a name outside it is ignored: a link shows without an icon, and a [page action](/sites/customize/navigation#page-actions) falls back to `arrow-up-right`. You can use `arrow-left`, `arrow-right`, `arrow-up-right`, `bell`, `book`, `book-marked`, `book-open`, `bookmark`, `box`, `briefcase`, `building-2`, `calendar`, `chart-line`, `check`, `chevron-down`, `circle-check`, `circle-help`, `clock`, `close`, `cloud`, `code`, `compass`, `copy`, `cpu`, `credit-card`, `database`, `dollar-sign`, `download`, `external-link`, `file-text`, `flag`, `gift`, `git-branch`, `github`, `globe`, `graduation-cap`, `handshake`, `headphones`, `heart`, `house`, `image`, `info`, `layers`, `layout-dashboard`, `library`, `life-buoy`, `lightbulb`, `link`, `linkedin`, `lock`, `mail`, `map`, `megaphone`, `menu`, `message-circle`, `message-square`, `mic`, `monitor`, `moon`, `newspaper`, `notebook-pen`, `octagon-alert`, `package`, `palette`, `pen-line`, `play`, `plus`, `puzzle`, `rocket`, `rss`, `search`, `settings`, `shield`, `sparkles`, `star`, `sticky-note`, `sun`, `tag`, `terminal`, `text-align-start`, `triangle-alert`, `trophy`, `user`, `users`, `video`, `wrench`, `x`, `youtube`, `zap`.

## Site

| Setting | Type | Default | Description |
| --- | --- | --- | --- |
| `$schema` | string | | The JSON Schema URL, for your editor |
| `name` | string, 1 to 80 characters | **Required** | Site name in the header, titles, share images and `llms.txt` |
| `description` | string, up to 300 characters | | Site description, and the fallback for section descriptions |
| `theme` | `"notra"` | `"notra"` | The only theme so far |
| `logo` | Path, or `{ light, dark, href? }` | | Header logo, and `href` sets where it links to. See [details](/sites/customize/navigation#logo-and-favicon) |
| `favicon` | Path, or `{ light, dark }` | | Browser tab icon |

## Navigation

| `navbar.links` | Up to 8 of `{ label, href, icon? }`, `{ type, href, label? }` or `{ label, icon?, items }` | `[]` | Header links or dropdowns with 1–8 non-nested links; `type` is `github`, `discord`, `x`, `linkedin`, `youtube` or `slack`; internal links show their active state |

| `navbar.cta` | `{ label, href }` | | Main call to action |
| `footer.links` | Up to 16 links, or up to 6 `{ header?, items }` columns with 1 to 12 links | `[]` | Footer links |
| `footer.socials` | Object of platform → URL | `{}` | `x`, `github`, `linkedin`, `youtube`, `discord`, `slack`, `instagram`, `facebook`, `bluesky`, `threads`, `reddit`, `medium`, `telegram`, `hacker-news`, `website` |
| `banner.content` | Markdown, 1 to 300 characters | **Required** in `banner` | One line across the top of every page |
| `banner.type` | `"info" \| "warning" \| "critical"` | `"info"` | Banner color |
| `banner.color` | Color, or `{ light, dark }` | | Your own banner color |
| `banner.dismissible` | boolean | `false` | Show a close button |
| `contextual.options` | Up to 12 of `copy`, `view`, `chatgpt`, `claude`, `t3chat`, `perplexity`, `grok` or `{ title, href, description?, icon? }` | All built-ins except `t3chat` | [Page actions](/sites/customize/navigation#page-actions) on blog posts and opted-in changelog entries; `[]` hides all actions |
| `contextual.display` | `"meta" \| "none"` | `"meta"` | `meta` shows actions below the page heading; `none` hides them in both areas |

## Authors

`authors` is an object that maps each author id to an author. Posts can also describe authors in their frontmatter. See [Authors](/sites/posts#authors).

| Setting | Type | Description |
| --- | --- | --- |
| id | Lowercase letters, digits and dashes, 1 to 40 characters | Used in a post's `author` |
| `name` | string, 1 to 80 characters, **required** | Display name |
| `title` | string, up to 80 characters | Role, like "Engineer" |
| `avatar` | `/path` or `https://` URL | Profile picture |
| `bio` | string, up to 300 characters | Short bio on the author page |
| `url`, `x`, `linkedin`, `github`, `youtube` | URL | Profile links |

## Redirects

`redirects` is a list of up to 500 rules. See [Redirects](/sites/customize/seo#redirects).

| Setting | Type | Default | Description |
| --- | --- | --- | --- |
| `source` | Path starting with `/` | **Required** | Full path on your domain, ending in `/*` to match everything below it |
| `destination` | `/path` or `https://` URL | **Required** | Where to send readers, ending in `/*` to keep the rest of the path |
| `permanent` | boolean | `true` | `308` when true, `307` when false |

## Variables

`variables` is an object that maps names to values, which you use as `{{ name }}` in posts. See [Variables](/sites/posts#variables).

Names start with a letter and use letters, digits, `_` and `-`, up to 40 characters, and values are up to 500 characters. Variables also work in `description`, `banner.content`, `markdown.instructions` and the `title` and `description` of `blog` and `changelog`.

## Integrations

For step-by-step setup in the dashboard or repository, see [Analytics integrations](/sites/integrations/analytics/overview). Provider scripts run on the live production site only, after you publish and deploy the configuration. Drafts, previews and local development do not activate them.

| Setting | Format |
| --- | --- |
| `integrations.databuddy.clientId` | Public Databuddy Client ID from your website's tracking code |
| `integrations.databuddy.*` | Optional tracker options such as `trackWebVitals`, `trackErrors`, `samplingRate`, `skipPatterns`, `apiUrl` and `replay`. See [Databuddy](/sites/integrations/analytics/databuddy#options) for every option |
| `integrations.ga4.measurementId` | Public Google Analytics 4 web stream Measurement ID, starting with `G-`, like `G-ABC123XYZ9` |
| `integrations.plausible.domain` | Your domain as added in Plausible, like `acme.com` |
| `integrations.plausible.server` | Optional self-hosted server hostname with an optional port, like `plausible.acme.com:8443`, without a protocol or path. Defaults to `plausible.io`; requests use HTTPS |
| `integrations.posthog.apiKey` | Starts with `phc_` |
| `integrations.posthog.apiHost` | An `https://` URL, with the default `https://us.i.posthog.com` |
| `integrations.posthog.sessionRecording` | Boolean, defaults to `true`. Set to `false` to disable recording while keeping analytics |
| `integrations.umami.websiteId` | Public Website ID as a UUID from Umami's Tracking code |
| `integrations.umami.scriptUrl` | Optional full HTTPS script URL. Defaults to `https://cloud.umami.is/script.js`; supports self-hosted script paths and ports |
| `integrations.c15t.backendURL` | Your Inth project URL or self-hosted c15t backend, as an `https://` URL. Turns on the cookie banner. See [c15t cookie banner](/sites/integrations/consent/c15t) for every `c15t` option |
| `integrations.c15t.scripts` | Object that maps custom script paths, like `scripts/hotjar.js`, to `measurement`, `marketing`, `functionality` or `experience`. Listed scripts load only after the visitor allows that category |
| `integrations.umami.hostUrl` | Optional HTTPS collection base URL, corresponding to `data-host-url`. Leave empty unless events should go to a different endpoint |

## Full example

```json blog.json
{
  "$schema": "https://usenotra.com/schemas/blog.json",
  "name": "Acme",
  "description": "Notes from the Acme team.",
  "logo": { "light": "/images/logo.svg", "dark": "/images/logo-dark.svg", "href": "https://acme.com" },
  "favicon": "/images/favicon.svg",
  "colors": { "primary": "#0D9373", "light": "#55D799" },
  "fonts": { "family": "Inter" },
  "navbar": {
    "links": [{ "label": "Docs", "href": "https://acme.com/docs" }],
    "primary": { "type": "github", "href": "https://github.com/acme/acme" },
    "cta": { "label": "Sign up", "href": "https://acme.com/signup" }
  },
  "footer": {
    "links": [{ "label": "Privacy", "href": "https://acme.com/privacy" }],
    "socials": { "x": "https://x.com/acme", "github": "https://github.com/acme" }
  },
  "blog": { "title": "Acme Blog", "layout": "magazine", "card": { "image": true } },
  "changelog": { "title": "What's new", "layout": "timeline" },
  "authors": {
    "jan": { "name": "Jan Burzinski", "title": "Engineer", "avatar": "/images/team/jan.jpg" }
  },
  "variables": { "product": "Acme Flow" },
  "redirects": [{ "source": "/blog/old-post", "destination": "/blog/new-post" }],
  "integrations": { "plausible": { "domain": "acme.com" } }
}
```
